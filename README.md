# readme-slot-probe

> **Test fixture, not an advertisement.** This repository is a test fixture for a private technical lab that studies how README images and links behave on GitHub. Every sponsor name here is fictional: there is no real company, product, offer, or payment.
>
> The images below are lab instrumentation served by a test server. Loading them records an anonymous request (path, time, and the proxy's user agent). No cookies are set and no IP addresses are stored. Nothing here needs any action from you.
